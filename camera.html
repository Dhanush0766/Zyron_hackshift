Setup and troubleshooting

  1. Replace the example stream URL in this file if your ESP32-CAM uses a different IP or endpoint.
  2. Open this page through your local web server (for example, http://localhost:5500/camera.html), not by double-clicking the file.
  3. Your computer and ESP32-CAM must be on the same network. Test the stream URL directly in a browser first.
  4. For browser-side analysis, the stream must be readable by canvas. The ESP32-CAM response needs the CORS header Access-Control-Allow-Origin: * (and a compatible response to any preflight request, if applicable).
  5. If you cannot change the ESP32 firmware, use a small same-origin server-side proxy that relays the stream and adds the appropriate CORS headers. Do not use a public CORS proxy for private camera video.
